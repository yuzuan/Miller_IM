# Miller-IM recurrence analysis

This repository provides the final English reproducibility package for the October 2026 revision of **An inflammatory myeloid program is enriched at recurrence in paired IDH-wildtype glioblastomas**.

The analysis scripts, figure source tables and reproduction instructions are in the [NOA R1 package](NOA_R1/README.md).

To redraw the five main figures from the supplied inputs, follow the [figure build instructions](NOA_R1/README.md#rebuild-figures-and-tables). The repository-level scripts, configuration and environment records support [raw-data preparation for NOA R1](docs/analysis_workflow.md).
